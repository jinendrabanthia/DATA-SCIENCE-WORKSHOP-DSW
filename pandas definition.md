derived from panel data . in econometrics this term is used for tabular data
the biggest difference is that pandas is designe for working with a tabular or heterogeneous data
basic data structures in pandas:
series: One-dimensional array-like object containing a sequence of
values (of similar types to NumPy types) of the same type and an
associated array of data labels, called its index.
DataFrame: a two-dimensional data structure that holds data like a
two-dimension array or a table with rows and columns.
